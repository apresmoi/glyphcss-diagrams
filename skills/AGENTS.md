# Skills

The repository guide applies. `glyphcss-diagrams` is the portable skill: copy its whole directory into a host's skills directory. It requires Node.js 22+ and no package installation.

- Default delivery is actual rendered text in the agent's reply. Files and other formats require an explicit request.
- Keep `SKILL.md` lean; less common authoring options belong in its linked reference.
- Edit `runtime/`, then regenerate the bundle from an explicit upstream glyphcss checkout: `node tools/build.mjs --source <path>` (or `npm run build -- --source <path>`). Commit the generated `scripts/render.mjs`, `scripts/lib/` and `NOTICE.txt` inside the skill so copies work outside this checkout.
- The bundle reuses the upstream library renderers. Do not fork their rendering algorithms, copy those packages into this repo, or introduce browser dependencies.
- Chat uses a 72×24 cell budget unless the destination supplies one; JSON line, area and bar charts start at `--size compact` (48×16) and the agent picks `wide`, `tall` or `full` from its data. Mermaid keeps 72×24. A success `hint` on stderr names a larger size only when the JSON default was outgrown. Only direct terminal output may read its own TTY dimensions. Never equate a tool PTY with the user's chat viewport.
- Chat radar without explicit charset uses braille outer contour/spokes and `radarSeries: "cells"` (•/○/×/+), for any series count; the chart reference recommends it for one series. Detect the parsed radar ledger; JSON has no radial annotation. Other chat charts containing a line or area default to braille; other charts and diagrams use box. Explicit `--charset` wins, and direct terminal output defaults to braille.
- Pies (`arc`) name every slice with its own callout: shade fills (`█ ▓ ▒ ░ ·`, ASCII `# = + : .` under `--charset ascii`) and no legend unless the spec sets `legend`. A slice too thin for a callout fails the render rather than going anonymous.
- The entrypoint shares one preprocessing function between JSON and Mermaid charts. Use public `glyphChartFromMermaid` for marks and `renderGlyphChartMermaid` with prepared options for rendering; preserve its charset-dependent radar parsing, flow-list sizing and both source ledgers.
- Heatmaps (`cell`-only charts) drop the axis lines unless the spec sets `axes.*.line`, and shade with braille dot density then blocks (`⠂⠢⠪⡪⣺⣿▒▓█`); `--charset ascii` keeps the library's ASCII ramp.
- An unfit failure's `hint` is per content kind: diagrams drop groups, then split into 6–8-node views; charts split Sankeys into ≤3-column stage ranges. Both point at `references/issues.md`, a user-approved issue report for apresmoi/glyphcss-diagrams.
- Stdout contains only rendered text (or explicit `--json` inspection output); stderr contains diagnostics. Fail before emitting incomplete graph connections or output outside the requested budget.
- Run `npm test` for runtime changes. It runs the portable tests against the committed bundles and does not need the upstream checkout. Real agent trials must run copied skills outside the repo and verify rendered text in the final replies, not just process exit codes. Preserve the evidence locally and report unavailable engines honestly.
